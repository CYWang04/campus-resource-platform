## 本轮范围与方案

覆盖登录、应用导航、学习空间、座位预约、教室申请、物业报修、通知中心、资源管理。
保留现有 API、权限条件与业务操作。没有新增后端字段、模拟业务数据、提交或推送。

- 黑白灰为基础，暖白色背景、深灰主按钮；成功、维修和异常状态保留低饱和语义色与文字。
- 侧栏使用双行字标、编号导航和选中下划线；顶部显示当前位置与当前用户。
- 登录页采用左侧编辑式标题与右侧表单；演示账号说明可展开查看。

- 各业务页统一标题、分区细线、双列表单与表格；通知改为带编号的文本列表。
- 小于等于 760px 时导航换行、表单单列、空间操作按钮换行；复杂表格保留组件内部横向滚动。
- 表单焦点可见；窄屏输入字体 16px；减少动态效果遵循系统偏好。

## 预览位置批注

2026-10-29 新增 `scripts/preview-annotations.js`，仅由 5174 预览脚本注入。刷新七个预览页面即可使用右下角工具：

1. 「添加批注」后点击需要修改的文字、表单或区域，填写并保存。标记模式下点击不会触发被标记控件的业务动作，按 Esc 退出。
2. 点击编号打开批注列表；可定位、编辑、删除，或切换「查看全部页面」。定位记录包含页面、元素路径、目标文本、元素内坐标比例与视口尺寸。布局变更后目标丢失的批注仍保留，可在列表中查看。
3. 批注保存在当前浏览器同源 localStorage。刷新或切换页面后保留；更换浏览器、端口或清理站点存储不共享。没有自动发送到聊天、服务器或 Git。
4. 完成后使用「导出修改清单」「导出定位数据」，将文件发送到聊天；也可「复制全部批注」后粘贴。
